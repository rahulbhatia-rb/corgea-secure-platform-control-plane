# Founding DevOps 30 / 60 / 90

## First 30 days
- map AWS/GCP accounts, services and trust boundaries
- baseline CI/CD duration and deployment frequency
- inventory secrets and static credentials
- define top-service SLOs
- map observability gaps
- baseline cost by workload
- review incidents and enterprise security asks

## By 60 days
- standard service template
- workload identity + managed-secret baseline
- security scanning in CI
- progressive deployment / rollback
- centralized logs, metrics and traces
- cost ownership and budget alerts
- runbooks and on-call ownership

## By 90 days
- executable platform policy gate
- multi-cloud service contract
- preview-environment automation
- artifact signing/provenance
- tested backup/restore
- incident exercise
- service scorecard across security, reliability, velocity and cost
