# Multi-Cloud Model

Multi-cloud should standardize outcomes, not hide the cloud.

Shared contract:
- identity model
- deployment policy
- service metadata
- observability schema
- SLOs
- security scanning
- cost ownership
- incident process

Provider implementation can differ:
- AWS IAM roles / workload identity patterns
- GCP Workload Identity
- AWS Secrets Manager vs GCP Secret Manager
- provider-native networking and telemetry
